Formatter

The formatter is plain JavaScript with no dependencies: strings in, strings out. The service worker uses it on responses, and the client runtime uses it for anything a page builds at runtime.

Source paths on this page are relative to packages/butter-col/.

URLs

rewriteUrl(raw, base) resolves raw against the target base URL, then encodes it as origin + prefix + codec.encode(url without fragment) + fragment.

InputResult (base https://example.com/dir/page, codec plain)
/a.pnghttps://proxy/butter/go/https%3A%2F%2Fexample.com%2Fa.png
b.png…/butter/go/https%3A%2F%2Fexample.com%2Fdir%2Fb.png
//cdn.test/x.js…/butter/go/https%3A%2F%2Fcdn.test%2Fx.js
https://a.test/p#frag…/butter/go/https%3A%2F%2Fa.test%2Fp#frag
#top, data:, blob:, mailto:, tel:, about:, javascript:Unchanged
An already proxied URLUnchanged (rewriting is idempotent)

unrewriteUrl(url) reverses it. If the proxied URL carries a raw ?query, that query replaces the target's, which matches how browsers resolve ?page=2 links and GET forms. Anything that isn't a proxied URL is returned unchanged.

Module workers get a ~m/ marker after the prefix (/butter/go/~m/…) so the service worker knows to prepend import rather than importScripts.

HTML

Service workers have no DOMParser, so src/formatter/html.js uses a small, forgiving tokenizer. Only start tags are touched. Text, comments, doctypes and end tags are copied byte for byte. A tag with no changes keeps its exact original source, including quoting and spacing.

<meta http-equiv="refresh">The URL inside content is rewritten.

Attribute values are entity-decoded before rewriting (&amp;, &lt;, numeric references, … following the HTML rule that legacy references without ; before = or alphanumerics are left alone) and re-escaped afterwards.

Injection

For documents, the service worker passes markup to inject. It goes immediately after <head>; if any other element starts first, it goes just before that element. Failing both, it goes after the doctype. It is never placed before the doctype, which would trigger quirks mode. The markup is:

<script data-butter>self.__butter$config={…};self.__butter$boot={"url":"…","cookies":"…"};</script>
<script src="/butter/client.js" data-butter></script>

The runtime deletes both globals and removes the two script[data-butter] elements once it has started.

CSS

url(…) in any quoting style and @import "…" strings are rewritten. url(#fragment) (SVG references) and data: URLs are left alone. Rewritten URLs are emitted as url("…") with quotes and backslashes escaped. Stylesheets with no url( or @import are returned untouched without scanning.

JavaScript

butter-col does not parse JavaScript into an AST. src/formatter/js.js is an error-tolerant tokenizer that understands strings, template literals (including nested ${}), comments, regular-expression literals and bracket nesting. It applies three kinds of edit:

SourceBecomesWhy
location, x.location, x?.location, x["location"]__butter$locationwindow.location can't be redefined, so code is pointed at an accessor the runtime controls.
eval(code)eval(__butter$js(code))Code built at runtime gets rewritten too, and the call stays a direct eval with access to local scope.
import.meta.url__butter$unrewrite(import.meta.url)So new URL("./x", import.meta.url) resolves against the real URL.

Edits are context-aware:

  • Object literal keys ({ location: 1 }) are kept, so JSON sent to servers is unchanged.
  • Shorthand properties ({ location }) become { location: __butter$location }.
  • import { location } from "x" becomes import { location as __butter$location } from "x".
  • export { location } becomes export { __butter$location as location }.
  • Method definitions named eval aren't wrapped.
  • Local variables named location are renamed consistently, which keeps them working.

Nothing inside strings, template text, comments or regex literals is ever changed. Sources that don't contain location, eval or import.meta skip the tokenizer completely.

__butter$location is a non-enumerable accessor on Object.prototype. On a window or document it returns that window's fake Location, and on a worker global the fake WorkerLocation. On any other object it simply reads and writes the object's own location property, so obj.location on ordinary objects keeps working after the rename.

createFormatter(config)

import { createFormatter } from "@axis-network/butter-col/formatter"; // or "/butter/formatter.mjs" in a page

const f = createFormatter({
  origin: "https://proxy.example.net", // the proxy's origin
  prefix: "/butter/go/",               // must match the server's config
  codec: "plain",                      // "none" | "plain" | "xor" | "base64"
});

dist/formatter.mjs is an ES module build of src/formatter/index.js, with type declarations in dist/types/. npm users import it as @axis-network/butter-col/formatter. The server serves it at /butter/formatter.mjs, and ButterController bundles it to encode URLs.

Methods

f.rewriteUrl(raw, base, { moduleWorker? })
Proxy URL for raw, resolved against base (string or URL).
f.unrewriteUrl(proxied)
The target URL, or the input unchanged if it isn't proxied.
f.html(source, { base, inject? })
Rewrite a document or fragment. Without inject, nothing is inserted (fragment mode).
f.css(source, base)
Rewrite a stylesheet or a style attribute.
f.js(source)
Rewrite a script. It doesn't need a base, because URLs in scripts are handled at runtime.
f.attr(tag, name, value, { base, inject? })
Rewrite one attribute value exactly as the HTML rewriter would. The runtime's setAttribute hook uses it.
f.refresh(value, base)
Rewrite the URL in a Refresh value such as "5; url=/next".
f.url.decodeTail(tail)
Decode what follows the prefix, or null if it isn't a valid encoded URL.
f.url.rewriteSrcset(value, base) / unrewriteSrcset(value)
Rewrite or un-rewrite every candidate in a srcset.
f.url.isProxied(url)
Whether a URL already points through the proxy.

Example

const page = await (await fetch("https://example.com/")).text();
const html = f.html(page, { base: "https://example.com/" });

f.js("if (location.hostname === 'example.com') location.href = '/home'");
// → "if (__butter$location.hostname === 'example.com') __butter$location.href = '/home'"

f.css("body { background: url(/bg.png) }", "https://example.com/");
// → 'body { background: url("https://proxy.example.net/butter/go/https%3A%2F%2Fexample.com%2Fbg.png") }'

Tests

test/formatter.test.mjs covers codec round-trips, URL rewriting, srcset, CSS, about twenty JavaScript edge cases (strings, regexes, templates, object keys, shorthand, import/export, eval) and HTML (injection position, entities, raw text, base, SVG). Run it with npm test.

Extending

  • A new URL attribute: add it to URL_ATTRS in html.js. Both the HTML rewriter and the runtime's attribute hooks pick it up.
  • A new codec: add { encode, decode } to codecs.js, and add its name to CODECS in server/lua/butter/config.lua and in lib/index.js (static deployments). Make sure decode(encode(x)) === x.
  • A new JS rewrite: add it to the identifier branch of rewriteJs, emit edits, never change text inside non-code tokens, and add tests for strings, comments and regexes.
