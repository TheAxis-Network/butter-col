Lua · OpenResty

Transport server

Validates every target, resolves and pins DNS against private ranges, keeps an HttpOnly cookie jar per session and streams responses through nginx.

TypeScript

Service worker

Intercepts proxied pages, rebuilds Referer, Origin and Sec-Fetch headers, and hands every request to the active transport: the built-in one, Bare, or one you write yourself.

JavaScript

Formatter

Rewrites HTML, CSS and JavaScript, then installs runtime hooks for location, the DOM, fetch, WebSockets, cookies and storage.

npm · @axis-network
